# សេចក្តីណែនាំអំពីការប្រើប្រាស់ប្រព័ន្ធគ្រប់គ្រង និងទម្រង់ឯកសារស្តង់ដាសាលាបឋមសិក្សាគំរូ
### សាលាបឋមសិក្សាតាពីង - ស្រុកដំណាក់ចង្អើរ ខេត្តកែប (លេខកូដសាលា៖ 22020204012)

---

## ១. ការបើកដំណើរការកម្មវិធី
- សូមបើកឯកសារ **`index.html`** ដោយចុចពីរដង (Double Click) លើឯកសារនោះ ដើម្បីបើកនៅលើ Google Chrome, Microsoft Edge, Mozilla Firefox ឬកម្មវិធីរុករក (Web Browser) ណាមួយ។

## ២. រចនាសម្ព័ន្ធនៃប្រព័ន្ធ
ប្រព័ន្ធនេះត្រូវបានរៀបចំឡើងយ៉ាងផ្ចិតផ្ចង់ និងត្រឹមត្រូវតាមសៀវភៅគោលការណ៍ណែនាំស្តីពី **«ស្តង់ដាសាលាបឋមសិក្សាគំរូ»** របស់ក្រសួងអប់រំ យុវជន និងកីឡា (ទំព័រទី១១ ដល់ ៣៥) ដែលរួមមាន៖
1. **ប៊ូតុងធំៗទាំង ៥ (តំណាងឱ្យស្តង់ដាទាំង ៥)**៖
   - **ស្តង់ដាទី១៖ លទ្ធផលសិក្សារបស់សិស្ស** (៥ សូចនាករគន្លឹះ / ១២ សូចនាកររង)
   - **ស្តង់ដាទី២៖ ការបង្រៀននិងរៀន** (៩ សូចនាករគន្លឹះ / ២៩ សូចនាកររង)
   - **ស្តង់ដាទី៣៖ ការចូលរួមរបស់សហគមន៍** (៣ សូចនាករគន្លឹះ / ៥ សូចនាកររង)
   - **ស្តង់ដាទី៤៖ ដំណើរការប្រតិបត្តិការ និងរដ្ឋបាលសាលារៀន** (៦ សូចនាករគន្លឹះ / ២០ សូចនាកររង)
   - **ស្តង់ដាទី៥៖ គណនេយ្យភាពរបស់សាលារៀន** (៣ សូចនាករគន្លឹះ / ៥ សូចនាកររង)
   - **សរុបរួម៖** ២៦ សូចនាករគន្លឹះ និង ៧១ សូចនាកររង / គំរូទម្រង់ឯកសារពេញលេញ!

2. **លេខសម្គាល់សូចនាកររងនៅលើឯកសារ (ID Code)**៖
   - រាល់ទម្រង់ឯកសារទាំងអស់ មាន **ប្រអប់លេខសម្គាល់ច្បាស់លាស់នៅផ្នែកខាងស្តាំខាងលើនៃឯកសារ** (ឧទាហរណ៍៖ `១.១.១`, `១.១.២`, `២.១.១`...) ស្របតាមការណែនាំរបស់អ្នកប្រើប្រាស់។

3. **មុខងារសំខាន់ៗក្នុងប្រព័ន្ធ**៖
   - **ស្វែងរកលឿន (Search Bar)**៖ អាចវាយស្វែងរកតាមលេខកូដ (ឧ. `១.១.២`) ឬតាមឈ្មោះសូចនាករ ឯកសារតម្រូវ។
   - **មើលគំរូទម្រង់ឯកសារ (View Template)**៖ បង្ហាញក្បាលសំបុត្រផ្លូវការ ព្រះរាជាណាចក្រកម្ពុជា ក្រសួងអប់រំ សាលាបឋមសិក្សាតាពីង ចំណងជើង និងតារាងទិន្នន័យ។
   - **កែសម្រួលទិន្នន័យផ្ទាល់លើសន្លឹក (Interactive In-Sheet Editing)**៖ លោកគ្រូ-អ្នកគ្រូអាចចុចផ្ទាល់លើតារាង ក្បាលតារាង ព័ត៌មានទូទៅ កំណត់សម្គាល់ ឬហត្ថលេខា ដើម្បីវាយបញ្ចូលទិន្នន័យជាក់ស្តែង ព្រមទាំងអាច **បន្ថែមជួរដេកថ្មី** ឬ **លុបជួរដេក** បានយ៉ាងងាយស្រួល។
   - **រក្សាទុកទិន្នន័យកែប្រែ (Save to LocalStorage)**៖ មានប៊ូតុង **«រក្សាទុក» (Save)** ពណ៌បៃតងយ៉ាងច្បាស់ ដើម្បីរក្សាទុកនូវរាល់ទិន្នន័យដែលបានកែសម្រួលក្នុងប្រព័ន្ធ មិនបាត់បង់ពេលបិទផ្ទាំង ឬបើកឡើងវិញឡើយ។
   - **កំណត់ត្រឡប់ទៅជាទម្រង់ដើម (Reset to Default)**៖ មានប៊ូតុង **«កំណត់ឡើងវិញ»** ប្រសិនបើចង់សម្អាតការកែប្រែ ហើយត្រឡប់ទៅទម្រង់គំរូលំនាំដើមវិញ។
   - **សម្គាល់ឯកសារដែលបានកែប្រែ (Customized Badge)**៖ បង្ហាញស្លាកពណ៌បៃតង **«បានកែប្រែ»** នៅលើ Card នៃសូចនាករដែលបានកែប្រែ និងរក្សាទុក។
   - **គ្រប់គ្រង និងបញ្ចូលភស្តុតាង (Evidence Management)**៖ ប៊ូតុង **«ភស្តុតាង»** (ជំនួសប៊ូតុង Word នៅលើ Card) សម្រាប់ចុចបញ្ចូលរូបភាពសកម្មភាព ឬឯកសារស្កេនជាភស្តុតាងគាំទ្រ។ មានប៊ូតុង **«បន្ថែមប្រអប់បញ្ចូល (+)»** សម្រាប់បន្ថែមប្រអប់រូបភាពមិនកំណត់ ព្រមទាំងមានការបង្រួមទំហំរូបភាពស្វ័យប្រវត្តិ។
   - **បង្ហាញភស្តុតាងនៅទំព័របន្ទាប់ (Annex on Next Page)**៖ រាល់រូបភាព និងភស្តុតាងដែលបានបញ្ចូល នឹងបង្ហាញដោយស្វ័យប្រវត្តិនៅ **ទំព័រទី ២ (ឧបសម្ព័ន្ធ) នៃឯកសារក្នុងប៊ូតុង «មើលគំរូ»** ដោយបែងចែកជា Grid រូបភាពស្អាតបាត មានចំណងជើង កាលបរិច្ឆេទ ការពិពណ៌នា និងប្លុកហត្ថលេខាបញ្ជាក់ត្រឹមត្រូវ។
   - **បោះពុម្ពផ្លូវការ (Print / Save PDF)**៖ រៀបចំទ្រង់ទ្រាយក្រដាស A4 ស្អាតបាតស្វ័យប្រវត្តិ ដោយលាក់ប៊ូតុង និង Menu ផ្សេងៗពេលបោះពុម្ព។ ប្រសិនបើមានភស្តុតាង ប្រព័ន្ធនឹងបោះពុម្ពទំព័រទី១ (ទម្រង់ឯកសារ) និងទំព័រទី២ (ឧបសម្ព័ន្ធភស្តុតាង) ដោយមាន Page Break ត្រឹមត្រូវ។
   - **ទាញយកជា Word (.doc)**៖ អាចទាញយកឯកសារដែលមានទិន្នន័យកែប្រែរួចជាស្រេច (រួមទាំងរូបភាពភស្តុតាងក្នុងឧបសម្ព័ន្ធ) ទៅប្រើប្រាស់ក្នុងកម្មវិធី Microsoft Word ដោយរក្សាទម្រង់អក្សរ និងតារាងបានយ៉ាងល្អឥតខ្ចោះ។
   - **ទាញយកបញ្ជីទាំង ៧១ (Export CSV/Excel)**៖ ទាញយកតារាងសង្ខេបនៃសូចនាកររង និងឯកសារកូឡោនទី២ទាំងអស់។
